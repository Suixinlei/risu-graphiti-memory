# v0.1.2 · RisuAI 长期记忆插件首次发布

为长篇角色扮演提供基于 Graphiti/Neo4j 的叙事记忆：生成前召回相关事实，生成后异步抽取本轮事件和关系，保留旧事实的失效信息。此版本沿用已有 0.1.2 业务实现，补齐使用文档、开发约定、验证记录和下载产物，适合本机早期试用。

## 下载与安装

- **plugin.js**：RisuAI → 设置 → 插件 → ＋，选择该文件并授予 replacer 权限。
- **neo4j-browser.zip**：四条只读 Cypher 和 Browser 指南，包含会话概览、关系图谱、事实时间线、入库记录。
- **SHA256SUMS**：下载附件后用 `shasum -a 256 -c SHA256SUMS` 核对。

插件还需要本机 sidecar、Neo4j，以及可用的抽取 LLM 和 embedding API。完整步骤见 [README](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.1.2/README.md#安装)。仅用 Compose 启动 Neo4j，sidecar 从 Python 源码运行。

Neo4j 启动后从 http://127.0.0.1:7474/browser/ 访问 Browser；具体连接和图谱查询见 [Browser 指南](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.1.2/docs/neo4j-browser/README.md)。

## 验证与限制

通过类型检查、构建、Python 语法、插件元数据及版本核对、合成数据离线导出检查。Browser 已在本机连接已有 Neo4j，四条只读查询和可视化已检查，没有数据库写入。完整证据见 [验证记录](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.1.2/docs/verification/v0.1.2.md)。

本次未进行真实 RisuAI + Neo4j + 模型端点的完整生成/抽取复验，也未验证新环境安装或手机访问。

已知问题没有在本次修复：提交失败仍推进游标、队列不持久化且无 worker 自动重试、不同回填窗口可能发生名称碰撞、剧情年份固定 2026、全局名册含特定故事角色。首次使用其他角色卡前应移除或替换名册；续传仅用于同一份固定 JSONL。详见 [功能 Review](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.1.2/docs/review-2026-10-28.md)。
