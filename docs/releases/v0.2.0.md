# v0.2.0 · 只根据 assistant 回复的异步长期记忆

在线记忆改为捕获 RisuAI 已提交的正式 assistant 输出，在后台摘要并提取图谱。修复 v0.1.3 将 Hypa V3 辅助摘要误当作聊天回复的问题，支持普通和流式输出；可以保留 Hypa 过渡，减少依赖时先确认所需旧历史已补齐，再关闭 Hypa。

- 插件先持久保存原文到 outbox；sidecar 持久保存 AssistantTurn，再异步摘要、入图。只有协议 3 的 completed 回执确认完成，失败保留原文，重启恢复未完成任务。
- 摘要使用 `<assistant_summary>...</assistant_summary>`；缺少结尾或格式异常即失败，不把半截摘要写入图谱。
- 召回窗口之外的近期 assistant 摘要和相关事实。沿用 RisuAI 滑动窗口，只追加独立记忆块，不压缩、替换或删除已有消息。
- 历史显式使用 --assistant-only 导入；旧 Hypa 摘要、旧图谱、旧 outbox 不自动迁移或删除，旧 live-v2 在线提交会被拒绝。
- Neo4j Browser 新增 assistant 摘要/任务状态查询。

## 安装与升级

**插件和 sidecar 必须同时升级到 v0.2.0；不能只替换 JS。** 服务启动后确认 /health 包含 assistant_memory_protocol=3，再导入 plugin.js、按提示更新/授予权限并刷新 RisuAI。无需升级或重启 RisuAI 本体。

- [已有 6001 的逐步安装指南](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.2.0/docs/install-6001.md)
- [全新安装与配置](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.2.0/README.md)
- **plugin.js**：RisuAI 插件。
- **neo4j-browser.zip**：五条只读查询与 Browser 说明。
- **install-6001.md**：可下载的 6001 升级、Hypa 切换与回退指南。
- **SHA256SUMS**：将上述三份文件下载到同一目录，执行 `shasum -a 256 -c SHA256SUMS`。

新装只记后续正式回复，不自动回填旧聊天；未回填的旧剧情不承诺可召回。保留现有数据库卷、.env、Hypa 数据及插件本地存储。

## 验证与限制

最后收尾按用户要求做轻量检查：14 项本地 HTTP 标识检查、12 组回填整理对照、类型检查、构建、Python 语法和离线发布检查通过；没有为最终发布重跑完整 E2E，也未新增真实模型调用。开发过程中的独立副本验收包括 Hypa 双开来源隔离、流式捕获、任务恢复及保留原始窗口消息，不能视为所有模型/宿主版本的兼容保证。

[验证范围与证据](https://github.com/Suixinlei/risu-graphiti-memory/blob/v0.2.0/docs/verification/v0.2.0.md)。语义抽取仍有不确定性；固定剧情年份、单进程、无认证和本机访问等限制见 README。本次发布没有改动现有 6001、sidecar 或 Neo4j 运行实例。
