# v0.1.2 发布验证

日期：2026-10-28（Asia/Shanghai）。本页的离线检查只使用本仓库与合成数据，不访问现有 RisuAI、Neo4j、抽取或 embedding 服务。用户随后追加的本机 Browser 配置和数据库只读验证见 [独立记录](neo4j-browser-2026-10-28.md)。

## 隔离检查前的失败场景清单

在编写检查脚本前明确以下风险：TypeScript 类型失败；构建失败；元数据头丢失或版本不一致；Python 语法错误；导出消息数量不符；角色标签丢失；Thoughts/statusData/trim 泄漏到正文；剧情时间丢失或错误；同批最新时间及后续时间继承错误；不同导出范围 episode 名称碰撞；相对文档链接缺失；JS 附件内容与摘要不符。追加 Browser 打包前补充检查项：归档损坏、文件遗漏、误包含凭据/真实查询结果、摘要不匹配；归档仅允许六个指定公开文档/查询文件。

其中名称碰撞是需复现并记录的已知缺陷，不代表通过数据完整性验收。脚本是离线 CLI 端到端与构建检查，不是单元测试，也不是产品全链路 E2E。

## 复现

环境：Python 3.10+、Node.js 18+、npm。先在 plugin/ 执行 npm ci，再从仓库根目录执行：

```bash
python3 docs/verification/check_release.py
git diff --check
```

脚本执行 typecheck/build，检查发布头与 package/lockfile 版本，解析 Python 源码，创建临时合成 JSON dump，通过 subprocess 调用真实 backfill.py export，并清理临时目录。无网络模型调用，不读取 sidecar/.env。构建会更新被 Git 忽略的 plugin/dist/，生成六个公开文件组成的 neo4j-browser.zip，并为 JS 和 ZIP 生成 SHA256SUMS。

## 结果

类型检查、构建、版本/元数据、10 个 Python 文件语法、合成历史导出及相对文档链接检查均通过。结果和 JS SHA-256 见同目录 [原始输出](v0.1.2-checks.txt)。名称碰撞已复现，以 KNOWN LIMITATION 输出，不表示该缺陷已修复；其余断言失败则进程非零退出。

mkdir -p /tmp/graphmem-release-verification

  --dir /tmp/graphmem-release-verification \
  --pattern plugin.js --pattern neo4j-browser.zip --pattern SHA256SUMS
