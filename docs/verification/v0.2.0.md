本版将在线记忆改为正式 assistant 输出事件 → 持久任务 → 后台摘要 → 图谱，移除额外上下文压缩。按用户最新要求，最后收尾采用轻量本地检查，没有为发布重跑完整 E2E 或再次调用真实模型。

- TypeScript 类型检查、构建、版本/JS 元数据一致、Python 语法、离线导出 CLI、文档链接与 git diff --check。
